# Nikolai Kushner

I build interfaces that stay fast when the data gets messy — dashboards with thousands of rows, filters that need to feel instant, and tools people rely on every day.

Right now, I'm building [**vibenglish.app**](https://vibenglish.app/) end to end — English for Russian speakers, a few minutes a day: FSRS-scheduled vocabulary review, grammar A1–B2, a level test, short stories and speaking practice, plus groups that teachers share by link. On the side I make small, local-first tools for working alongside AI coding agents.

**Main stack:** TypeScript · Vue · Nuxt · Next.js · Node.js · PostgreSQL · Swift (macOS / iOS)

**Also working with:** Prisma · Tailwind CSS · Vite · Vitest · Playwright · Astro
